# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please do NOT report it in public issue trackers.

Instead, please report security issues by contacting our security team via email or private channels.

### What to include in your report

When reporting a vulnerability, please include:
- A detailed description of the issue and potential impact.
- Step-by-step instructions or proof-of-concept code to reproduce the issue.
- Any suggested mitigations or fixes.

### What to expect

- **Acknowledgement:** We aim to acknowledge receipt of your report within 48 hours.
- **Assessment:** We will investigate and verify the report as quickly as possible.
- **Resolution:** We will work on a fix and publish an update once resolved.

Thank you for helping keep our project and community safe.
