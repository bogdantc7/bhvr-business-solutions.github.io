# Security Policy

## Supported Versions

Only the latest main branch of this repository is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please follow responsible disclosure practices:

1. **Do NOT open a public issue or pull request** describing the vulnerability.
2. Report the vulnerability privately to the maintainers or security team.
3. Provide detailed steps to reproduce the issue along with any relevant proof-of-concept code.

### What to expect

- **Response Time:** We aim to acknowledge receipt of security reports within 48 hours.
- **Assessment:** We will evaluate the report and determine appropriate remediations.
- **Updates:** We will keep you updated on the progress towards resolving the vulnerability.

Thank you for helping keep this project secure!
