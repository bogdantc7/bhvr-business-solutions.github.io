# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it responsibly.

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, please submit security reports via GitHub Private Vulnerability Reporting or contact project maintainers.

### What to Include in Your Report

- A clear description of the issue and its potential security impact.
- Step-by-step instructions to reproduce the vulnerability.
- Any proof-of-concept code or details if available.

## Response Guidelines

- We aim to acknowledge vulnerability reports within 48 hours.
- Confirmed issues will be addressed promptly with patches or mitigations.

Thank you for helping keep this project secure!
