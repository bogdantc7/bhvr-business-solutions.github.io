# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you discover or suspect a security vulnerability, please follow responsible disclosure guidelines.

**Do NOT report security vulnerabilities via public GitHub issues, discussions, or pull requests.**

### How to Report

Please report security issues privately by contacting the security maintainers or sending details to our security team/contacts.

When reporting a vulnerability, please include:
- A description of the issue and its potential impact.
- Detailed steps to reproduce or a Proof of Concept (PoC).
- Any suggested mitigations or patches, if available.

### Preferred Response Time

We will acknowledge receipt of your vulnerability report as soon as possible and provide updates as the issue is investigated and remediated.

Thank you for helping keep this project safe!
