# Security Policy

## Supported Versions

Only the latest main branch release of this repository is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you suspect or discover a security vulnerability, please follow these guidelines to report it responsibly:

1. **Do NOT open a public issue** or discuss the vulnerability publicly.
2. Report the details of the vulnerability confidentially via GitHub Security Advisory or email security maintainers.
3. Include detailed steps to reproduce the issue, potential impact, and any mitigation steps if known.

### Response Timeline

- **Initial Acknowledgment:** Within 48 hours of report submission.
- **Status Update & Assessment:** Within 7 business days.
- **Fix & Patch Release:** Released as soon as reasonably possible following verification.

Thank you for helping keep this project safe!
