## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please follow these reporting guidelines:

1. **Do NOT** open a public GitHub issue for security vulnerabilities.
2. Email details of the vulnerability to the security team or maintainers privately.
3. Include detailed steps to reproduce the vulnerability, including proof-of-concept scripts or instructions if applicable.

### Preferred Security Contact

- Email: `security@example.com`

## Response Process

- **Acknowledgement:** We aim to acknowledge receipt of security reports within 48 hours.
- **Assessment:** We will assess the impact and severity of the reported issue.
- **Remediation:** If confirmed, a fix will be developed, tested, and released as quickly as possible.
