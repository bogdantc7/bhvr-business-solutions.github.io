## Reporting a Vulnerability

We take the security of our software seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

### How to Report

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report security issues privately by emailing security disclosures or submitting a GitHub Security Advisory if enabled.

Please include the following details in your report:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept code to reproduce the issue.
- Any suggested mitigations or fixes.

### Response & Disclosure

- We will acknowledge receipt of your report within 48 hours.
- We will evaluate the report and provide an estimated timeline for a fix.
- Once a fix is available, we will release a security update and coordinate public disclosure.

Thank you for helping keep our project and users safe!
