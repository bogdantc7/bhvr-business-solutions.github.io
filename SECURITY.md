## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please report it responsibly.

### Disclosure Process

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Please submit vulnerability details privately via GitHub Private Vulnerability Reporting (under the repository's **Security** tab -> **Report a vulnerability**).
3. Include detailed information:
   - Type of vulnerability/issue
   - Steps to reproduce or proof-of-concept
   - Potential impact of the vulnerability

### Response Timeline

- **Initial Acknowledgment:** Within 48 hours of receipt.
- **Status Update & Triage:** Within 5 business days.
- **Fix & Patch Release:** Priority critical/high issues will be addressed as promptly as possible.

Thank you for helping keep this project and its users secure!
