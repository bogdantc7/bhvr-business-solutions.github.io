## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do NOT create a public issue.

### Disclosure Process
1. Report security issues privately through GitHub Private Vulnerability Reporting or contact repository maintainers directly.
2. Provide a detailed explanation of the vulnerability and steps to reproduce.
3. Allow reasonable time for response and fix before taking further disclosure action.

We appreciate your effort in responsibly disclosing findings and keeping the community safe.
