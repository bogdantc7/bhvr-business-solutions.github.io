## Reporting a Vulnerability

We take the security of our application seriously. If you discover a security vulnerability, please follow responsible disclosure practices:

1. **Do NOT open a public issue or PR.**
2. Report the vulnerability privately to the project maintainers.
3. Provide detailed steps to reproduce the vulnerability, including proof-of-concept code or scenarios if available.

### What to Expect

- **Acknowledgement:** We will acknowledge receipt of your report within 48 hours.
- **Assessment:** We will investigate and assess the vulnerability's impact.
- **Fix & Disclosure:** A security fix will be released promptly, and appropriate credit will be given upon resolution.

Thank you for helping keep this project and its community safe!
