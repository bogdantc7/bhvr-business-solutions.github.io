# Security Policy

## Reporting a Vulnerability

We take the security of this repository seriously. If you discover a potential security vulnerability, please report it responsibly.

**Please do NOT report security vulnerabilities through public issue trackers.**

### How to Report

- Use **GitHub Private Vulnerability Reporting** via the "Security" tab of this repository if available.
- Alternatively, submit details directly to the repository maintainers via private channels.

### Report Content

When submitting a security report, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or a proof-of-concept to reproduce the issue.
- Any proposed remediation or mitigation steps.

### Responsible Disclosure Policy

- Please allow reasonable time for the maintainers to review and address the report before public disclosure.
- Do not attempt to access, modify, or destroy data belonging to other users.
- Do not execute denial-of-service (DoS) attacks or disrupt services.

Thank you for helping keep this project secure!
