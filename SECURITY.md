## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability:

1. **Do NOT open a public issue.**
2. Report via GitHub **Private Vulnerability Reporting** under the "Security" tab.
3. If unavailable, contact repository maintainers directly.

### Expectations

- **Initial Response:** Within 48 hours.
- **Updates:** Periodic status updates during remediation.
