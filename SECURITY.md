## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it responsibly.

**Please DO NOT open a public GitHub issue or discussion to report security vulnerabilities.**

### How to Submit a Report

Please submit security vulnerability reports privately using GitHub's **Private Vulnerability Reporting** feature:

1. Navigate to the **Security** tab of the repository.
2. Select **Advisories** and click **Report a vulnerability**.

Alternatively, if private vulnerability reporting is unavailable, please contact repository maintainers directly via private channels.

### What to Include in Your Report

When reporting a vulnerability, please provide:

- A clear description of the vulnerability and its potential impact
- Step-by-step reproduction instructions or a minimal proof-of-concept
- Any affected components, dependencies, or configurations
- Any proposed mitigations or fixes, if known

### Response Timeline

- **Acknowledgement:** Within 48 hours.
- **Triage & Assessment:** Within 5 business days.
- **Resolution & Release:** As soon as feasible depending on vulnerability severity.

Thank you for responsibly disclosing security issues and helping keep our community safe.
