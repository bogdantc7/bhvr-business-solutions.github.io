## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please follow responsible disclosure practices:

1. **Do not** report security vulnerabilities through public GitHub issues or discussions.
2. Please report vulnerabilities using GitHub's **Private Vulnerability Reporting** feature via the "Security" tab of this repository, or contact the repository maintainers directly.
3. Include detailed steps to reproduce the issue and any relevant code snippets.

### Response Timeline

- **Initial Response:** Within 48 hours
- **Status Update:** Within 7 business days
- **Fix / Advisory Release:** Priority-based patch release

Thank you for helping keep this project safe!
