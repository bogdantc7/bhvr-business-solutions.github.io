## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it responsibly.

**Please DO NOT report security vulnerabilities through public GitHub issues or discussions.**

### How to Submit a Report

Please submit vulnerability reports privately using GitHub's **Private Vulnerability Reporting**:

1. Navigate to the **Security** tab of this repository.
2. Under "Reporting", click **Report a vulnerability** to open the advisory form.

If private vulnerability reporting is unavailable, please contact the maintainers directly through secure, private channels.

### What to Include

To help us triage and resolve the issue quickly, please provide:

- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the behavior.
- Any suggested remediations or mitigations, if known.

### Response Timeline

- **Initial Response:** Within 48 hours.
- **Status Updates:** Periodic updates on triage and mitigation progress.
