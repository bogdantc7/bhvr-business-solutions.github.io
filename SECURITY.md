## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it responsibly.

**Please DO NOT open a public GitHub issue or discussion to report security vulnerabilities.**

### How to Submit a Report

Please submit security vulnerability reports privately using GitHub's **Private Vulnerability Reporting** feature:

1. Navigate to the **Security** tab of this repository.
2. Under "Reporting", click **Report a vulnerability** to open the advisory form.

If private vulnerability reporting is unavailable, please contact the project maintainers directly via private channels.

### What to Include

- Description of the vulnerability and its potential impact.
- Clear reproduction steps or proof-of-concept.
- Affected components or configurations.

### Response Timeline

- **Initial Response:** Within 48 hours.
- **Status Updates:** Within 5 business days.
