# Security Policy

## Supported Versions

Security updates are applied to the active default branch (`main`).

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please do **NOT** report it in public issue trackers or public pull requests.

### How to Report Privately

Please report security vulnerabilities privately using **GitHub Private Vulnerability Reporting**:
1. Navigate to the **Security** tab of this repository.
2. Select **Report a vulnerability** to open a private advisory.

### What to Include

When submitting a report, please include:
- A description of the vulnerability and its potential security impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue safely.
- Any suggested remediations or mitigations.

### Response Timeline

- **Acknowledgement:** We aim to acknowledge receipt within 48 hours.
- **Resolution:** We will investigate, develop a fix, and coordinate release details privately.
