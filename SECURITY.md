## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

### How to Submit a Report

Please report security vulnerabilities privately using GitHub's **Private Vulnerability Reporting** feature (via the **Security** tab of the repository) or by contacting project maintainers directly via private message.

Include the following details in your report:
- Description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Any suggested mitigations or fixes, if available.

### Response Timeline

- **Acknowledgement:** Within 48 hours.
- **Assessment & Status Update:** Within 5 business days.
- **Fix Release:** As soon as feasible depending on severity.

Thank you for helping keep this project secure!
