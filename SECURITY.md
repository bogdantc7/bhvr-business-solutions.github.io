## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it responsibly.

### How to Report

1. **Do NOT open a public issue** for security vulnerabilities.
2. Report the vulnerability using GitHub's **Private Vulnerability Reporting** feature via the "Security" tab of this repository.
3. If Private Vulnerability Reporting is unavailable, please contact the maintainers directly.

### What to Include

- Description of the vulnerability and potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Any suggested mitigations or fixes.

### Response Expectations

- **Initial Response:** Within 48 hours.
- **Status Updates:** Periodic updates as the issue is investigated and remediated.
