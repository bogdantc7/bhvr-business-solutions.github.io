# Security Policy

## Supported Versions

We actively maintain and provide security updates for the repository's default branch.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly:

1. **Do NOT** open a public issue or discussion regarding the vulnerability.
2. Email details of the vulnerability to security disclosure maintainers or contact repo owners privately.
3. Include detailed steps to reproduce the issue, potential impact, and any suggested mitigations.

We will acknowledge receipt of your vulnerability report promptly and work to address the issue as quickly as possible.
